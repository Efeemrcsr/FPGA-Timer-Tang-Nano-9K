# FPGA Hardware Timer & UART Receiver

## Overview
Digital logic and hardware description project developed for the Tang Nano 9K FPGA board. The project implements a hardware timer and a UART receiver using Verilog.

## Files
* `mydesign.v`: Main top-level Verilog module.
* `uart_rx.v` & `serial_template.v`: UART receiver logic for serial communication.
* `cs303.cst`: Physical pin constraints file for the Tang Nano 9K board.

## Tools Used
* Verilog HDL
* Gowin EDA
